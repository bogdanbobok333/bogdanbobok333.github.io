Privacy Policy

NotesPro for Windows (Microsoft Store ID 9N8NWX0D0VJN)
Developer: Bohdan Bobok · Effective date: 14 September 2026

This privacy policy explains what data the NotesPro desktop application for Windows (the “Application”) handles, where it is kept, and who it is shared with. Bohdan Bobok (the “Service Provider”) operates the Application as an independent developer.

Data the Application collects

The Application does not collect, transmit, sell, or share any personal information. It does not ask you to register, does not create an account, and does not collect your name, email address, phone number, contacts, or location. It contains no advertising, no analytics, and no tracking of any kind.

The Application does not use your microphone or camera.

Data stored on your device

Everything you create in the Application stays entirely on your computer. It is never uploaded or transmitted anywhere and is not readable by the Service Provider. This data is stored in your Windows user profile, in the %APPDATA%\Notes folder, and consists of:

  • Notes and categories — the titles, text, colours, pinned and completed state, and day counters of your notes.
  • Attached images and videos — when you attach a file to a note, a copy of that file is saved in the Application’s folder so the note keeps working if the original is moved. The Application only reads files that you explicitly select.
  • Reminders — the dates and times you set for your notes. Reminders are shown by the Application itself on your computer; no notification service or server is involved.
  • Settings — the selected theme, colour scheme, interface language, sorting options, and the position and size of the desktop widget.

You can back up, move, or delete this data yourself at any time.

System features the Application uses

To work as a desktop notes app, the Application runs as a regular Windows desktop program. It uses a system tray icon, an optional always-on-top desktop widget showing your notes, reminder pop-up windows, and a startup task that launches it when you sign in to Windows so that reminders arrive on time. You can turn the startup task off in Settings → Apps → Startup. None of these features send data anywhere.

Network use

The Application works fully offline and does not need an internet connection for notes, reminders, or the widget.

The only feature that may connect to the internet is the “Our apps” screen, which lists the developer’s other applications. If it is available in your version, it may load the icons of those applications from their public store pages. These requests contain no information about you or your notes. Opening an application from that screen launches the Microsoft Store app.

Purchases and Microsoft Store

The Application is distributed and sold through the Microsoft Store. Payment, licensing, downloads, and updates are handled entirely by Microsoft; the Service Provider does not receive your payment details. Microsoft Store and Windows may collect data under their own terms:

  • Microsoft Privacy Statement

Data security and retention

The Service Provider operates no servers and stores no user data. Your notes, attachments, and settings are kept on your computer for as long as you keep them, protected by the security of your Windows user account.

Deleting your data

Because the Service Provider does not store any of your data, there is nothing held by the developer that can be deleted on request. You can delete individual notes inside the Application, and you can remove all of its data by deleting the %APPDATA%\Notes folder or uninstalling the Application.

Children

The Application is a general-purpose notes tool and is not directed at children under the age of 13 (or under 16 in jurisdictions where that is the applicable age of digital consent). The Application does not collect data from anyone, including children.
