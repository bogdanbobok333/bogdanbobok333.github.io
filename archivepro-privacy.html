Privacy Policy

Archive Pro for Windows (Microsoft Store ID 9NW6N2QWNS1K)
Developer: Bohdan Bobok · Effective date: 23 September 2026

This privacy policy explains what data the Archive Pro desktop application for Windows (the “Application”) handles, where it is kept, and who it is shared with. Bohdan Bobok (the “Service Provider”) operates the Application as an independent developer.

Data the Application collects

The Application does not collect, transmit, sell, or share any personal information. It does not ask you to register, does not create an account, and does not collect your name, email address, phone number, contacts, or location. It contains no advertising, no analytics, and no tracking of any kind.

The Application does not use your microphone or camera.

Your files

Archive Pro opens, reads, extracts and creates archives entirely on your computer. The files you open or pack are never uploaded anywhere and never reach the Service Provider or any third party. The Application only touches files that you explicitly select, drag into its window, or open it with.

Data stored on your device

  • Settings — %APPDATA%\ArchivePro\settings.properties: interface language, light or dark theme, the folders you last chose for extracting and saving, and the window size.
  • Previewed files — when you open a single file straight from an archive, it is extracted to %LOCALAPPDATA%\ArchivePro\opened so that Windows can open it with the matching program. These copies are deleted the next time you close the Application.
  • Our apps cache — %LOCALAPPDATA%\ArchivePro\more_apps: the names and icons of the developer’s other Microsoft Store applications, so the screen works without an internet connection.

When the Application uses the internet

One screen uses the network: “Our apps”, which lists other applications by the same developer. To build that list, the Application requests public Microsoft Store product pages and downloads the application names and icons. This happens at most once a day.

These are ordinary web requests for public pages. They carry no information about you, your files or your computer, beyond what any web request necessarily reveals to the server it reaches (your IP address, handled by Microsoft under the Microsoft Privacy Statement). The result is cached locally, so with no internet connection the screen simply shows what is already known.

Nothing else in the Application touches the network.

Third parties

The Application uses no third-party analytics, advertising or crash-reporting services. The only external service it contacts is the public Microsoft Store website, as described above.

Children

The Application is suitable for all ages and knowingly collects no information from anyone, including children under 13.

Security

Because no data leaves your computer, there is nothing for the Service Provider to secure on your behalf. Archives you protect with a password are encrypted with AES-256; the password is never stored by the Application and is never transmitted.

Changes to this policy

This policy may be updated from time to time. The current version is always published at this address, and the effective date above is updated accordingly.
